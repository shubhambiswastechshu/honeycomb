# MCP data plane. FastAPI serves /mcp/* as its own ASGI app, mounted beside
# Django in Honeycomb/asgi.py rather than behind it: Django's middleware chain
# contains sync-only code (WhiteNoise), so routing MCP traffic through it would
# wrap every JSON-RPC call in a thread hop for no benefit. uvicorn is here for
# its worker class -- gunicorn runs `Honeycomb.asgi:application` through
# uvicorn.workers.UvicornWorker in production (see render.yaml) -- and its
# [standard] extras carry the C-accelerated HTTP and websocket parsers.
